# QuickHire — Your First Job Portal

Simple React SPA for browsing jobs (student/minor project).

Features:
- Home with search box and "Browse All Jobs" button
- Jobs list with filter buttons (All / Remote / Full-Time)
- Job detail page with description and "Apply Now" success message

Run locally:

```bash
npm install
npm run dev
# open http://localhost:5173
```

Built with Vite + React.
